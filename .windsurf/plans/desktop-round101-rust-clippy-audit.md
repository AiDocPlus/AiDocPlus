# Desktop Round101 计划

## 目标

- 在已基本完成 `allow` / `serde` 机械收口后，运行 `cargo clippy` 审计 Rust 侧剩余低风险机械清理机会。
- 优先挑选不改变外部接口、不影响运行行为的修复项。

## 执行步骤

1. 运行 `cargo clippy` 获取当前告警。
2. 过滤出低风险、机械性强的问题（如冗余样板、可读性/惯用法修复）。
3. 实施最小修改并避免触碰前后端接口兼容层。
4. 通过 `cargo check` 或 `cargo clippy` 复验。

## 约束

- 不改 Tauri command 参数形状。
- 不改前端调用协议与现有 JSON 字段名。
- 只做低风险机械修复，不做语义重构。
