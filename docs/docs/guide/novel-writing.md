# 小说写作功能

AiDocPlus 内置了完整的长篇小说写作辅助系统，涵盖从设定集管理、章节组织、AI 续写到全书导出的全流程。

---

## 快速开始

### 第一步：将项目转为小说项目

小说功能需要先将项目标记为"小说项目"。

1. 在左侧**文件树**中，找到你的项目名称
2. **右键点击**项目名称，弹出菜单
3. 选择 **「转为小说项目」**
4. 项目即刻进入小说模式

> 转换后，左侧边栏顶部会出现 **「文件 / 小说」** 两个切换 Tab。点击「小说」即可进入设定集管理面板。

如需取消小说模式，同样右键项目名 → 选择「取消小说模式」。

### 第二步：打开设定集面板

转为小说项目后：

1. 点击左侧边栏顶部的 **「小说」** Tab
2. 进入**设定集管理面板**，包含以下 9 个子页签：

| 页签 | 功能 |
|------|------|
| **概览** | 填写题材、时代、风格、大纲等基本信息 |
| **人物** | 管理所有角色（主角/反派/配角/龙套），包括名称、别名、对话风格 |
| **地点** | 管理地理位置，支持多级嵌套（如「王都 → 皇宫 → 金銮殿」） |
| **势力** | 管理组织势力及其成员 |
| **时间线** | 关键事件时间轴 |
| **自定义** | 自定义条目（魔法体系、种族设定等） |
| **伏笔** | 全局伏笔管理（未回收 / 已回收 / 已放弃） |
| **风格** | 风格语料库：导入参考作品，AI 自动分析风格画像 |
| **仪表盘** | 全书统计（字数、章节进度、伏笔状态、人物出场、导出） |

## 章节组织

### 创建卷和章节

小说项目的文件树会自动切换为**卷/章层级视图**：

1. 切换到左侧边栏的 **「文件」** Tab
2. 你会看到专用的小说文档树，提供：
   - **「添加卷」** 按钮 — 创建新的卷（如「第一卷 天命之子」）
   - **「添加章节」** 按钮 — 在当前卷下创建章节
3. 章节会自动归属到卷下，支持拖拽排序

### 章节大纲面板

打开任意章节文档后，右侧面板会出现 **「AI 聊天 / 章节大纲」** 切换 Tab：

1. 点击 **「大纲」** Tab，打开**章节大纲面板**
2. 可以编辑：
   - **本章大纲** — 描述本章情节走向和任务
   - **章节摘要** — 用于 AI 续写时的上下文记忆（Layer 2）
3. 摘要旁边有 **「AI 生成」** 按钮（紫色 ✨ 图标），点击即可让 AI 自动生成 200-500 字的精炼摘要
4. 面板底部还显示**本章相关伏笔**，可以：
   - 查看伏笔状态（未回收 / 已回收 / 已放弃）
   - 一键标记伏笔为「已回收」或「已放弃」
   - 快速添加新伏笔

## AI 小说续写

### 四层记忆系统

当你在小说章节中使用 AI 对话时，系统会自动构建**四层记忆上下文**，确保 AI 了解完整的故事背景：

| 层级 | 内容 | 说明 |
|------|------|------|
| **Layer 0** | 风格指导 | 设定集中的题材、时代、风格描述 |
| **Layer 1** | 设定集摘要 | 主要人物（含对话风格）、地点、势力、未回收伏笔 |
| **Layer 2** | 近章回顾 | 前 5 章的章节摘要（优先同卷） |
| **Layer 3** | 当前章节 | 本章大纲 + 正文尾部（约 2000 字） |

> 这意味着你**不需要手动复制粘贴上下文**，AI 会自动获取所需的所有信息。

### 六种续写模式

在聊天输入框底部，你会看到一个**续写模式选择器**（琥珀色羽毛图标）。仅在小说章节文档中显示。

| 模式 | 适用场景 |
|------|----------|
| **自由续写** | 默认模式，AI 自由发挥 |
| **大纲引导** | 严格按照章节大纲推进情节 |
| **对话生成** | 专注生成人物对话 |
| **环境描写** | 专注生成场景和环境描写 |
| **内心独白** | 生成角色的内心活动 |
| **过渡段落** | 生成场景转换和过渡文字 |

选择模式后，在聊天框中输入你的指令（如「继续写」、「让主角与师傅对话」），AI 会按照选定模式和四层记忆进行续写。

### 人物一致性检查

续写模式选择器旁有一个 **「一致性」** 按钮（绿色盾牌图标）：

1. 点击后，系统会先进行**本地快速检查**（检测文中是否出现设定集中未登记的人物名）
2. 然后调用 **AI 深度检查**（校验人物性格、关系、对话风格是否与设定集一致）
3. 检查结果会直接显示在聊天面板中

## 风格语料库

### 导入参考作品

1. 在设定集面板中点击 **「风格」** Tab
2. 点击 **「添加」** 创建新语料库（如「古龙全集」）
3. 展开语料库，点击 **「导入文本」**
4. 粘贴参考作品的文本内容，点击「导入」
5. 可以导入多个文件

### AI 风格分析

导入文本后，点击 **「分析风格」** 按钮：

- AI 会阅读样本文本，生成**风格画像**，包括：
  - 风格总述
  - 句式特征
  - 对话风格
  - 氛围营造
  - 标志性手法
- 分析结果会保存在语料库卡片中，随时查看

> 风格画像会在 AI 续写时作为 Layer 0 的参考，帮助 AI 模仿目标风格。

## 全书统计与导出

### 仪表盘

在设定集面板中点击 **「仪表盘」** Tab，查看：

- **总字数** — 全书字数和 AI 生成字数
- **章节进度** — 有正文/有大纲/有摘要的章节比例
- **伏笔状态** — 未回收/已回收/已放弃的伏笔分布
- **人物出场次数** — 各角色在全文中出现的频率排行
- **各章字数** — 每章字数一览

### 导出全书

在仪表盘右上角点击 **「导出全书」** 按钮：

- 自动按卷/章结构生成完整的 **Markdown 文件**
- 包含自动生成的**目录**（含各章字数）
- 下载为 `.md` 文件，可用任何编辑器打开

## 完整工作流示例

以下是推荐的小说写作工作流：

1. **创建项目** → 右键「转为小说项目」
2. **填写设定集** → 在「小说」Tab 中填写概览、人物、地点等
3. **创建卷/章结构** → 在文件树中添加卷和章节
4. **编写章节大纲** → 打开章节 → 右侧「大纲」Tab → 填写大纲
5. **AI 续写** → 在聊天框选择续写模式 → 输入指令
6. **一致性检查** → 写完后点击「一致性」按钮检查
7. **生成摘要** → 大纲面板中点击「AI 生成」摘要
8. **管理伏笔** → 在大纲面板底部添加/回收伏笔
9. **查看统计** → 仪表盘查看进度
10. **导出成书** → 仪表盘中导出全书 Markdown

## 常见问题

### 看不到小说相关功能？

确保已将项目转为小说项目：右键项目名 → 「转为小说项目」。

### 续写模式选择器在哪里？

仅在打开**小说章节或卷文档**时，聊天输入框底部才会显示续写模式选择器。确保当前文档的 `documentType` 为 `chapter` 或 `volume`。

### AI 续写时没有上下文？

请检查：
1. 是否已在设定集中填写了基本信息（概览 Tab）
2. 前序章节是否已生成摘要（Layer 2 需要摘要数据）
3. 当前章节是否已写入一些正文（Layer 3 需要当前内容）

### 如何让 AI 模仿特定作者的风格？

在「风格」Tab 中创建语料库 → 导入参考作品 → 点击「分析风格」，AI 会在续写时参考风格画像。
