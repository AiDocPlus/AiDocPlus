# 插件系统

AiDocPlus 内置 **28 个插件**（各插件目录下均有 `manifest.json`；`plugins/_framework/` 为插件 SDK，**不计入**插件数量），分为**内容生成类**（内容区，`majorCategory: content-generation`）与**功能执行类**（功能区，`majorCategory: functional`）。分类以 manifest 为准，应用内「插件管理」中的列表为最新。

## 进入方式

- 工具栏点击 **「内容区」** 或 **「功能区」** 按钮
- 菜单 **视图 → 内容区** 或 **视图 → 功能区**

## 插件工作流程

1. 切换到内容区或功能区
2. 从左侧列表选择插件
3. 在右侧面板中操作
4. 内容生成类插件的结果可写入文档或插件数据（依插件而定）

## 插件管理

通过 **设置 → 插件管理** 可以启用/禁用插件，调整显示顺序。
