## Bug 修复（下午）

### Bug 2: ImitativeWritingWorkspace setState 副作用错误
- **问题**：React 报错 "Cannot update a component (FileTree) while rendering a different component (ImitativeWritingWorkspace)"
- **根因**：`updateDoc` 在 `setDocContent` 的 state updater 内调用 `debouncedSave(next)`，而 `debouncedSave` → `updateDocumentInMemory` → Zustand `set()` → FileTree 重渲染，所有操作在渲染阶段同步完成
- **修复**：用 `docContentRef` 追踪最新 docContent，将 `debouncedSave` 移到 state updater 外部直接调用
- **文件**：`apps/desktop/src-ui/src/document-types/imitative-writing/ImitativeWritingWorkspace.tsx`（第 212-223 行）

### Bug 1: 翻译原文粘贴时译文区同步填充
- **问题**：在中英翻译工作区复制文本到原文区时，译文区也被填充了相同内容
- **根因**：两个 MarkdownEditor 共享默认 key，React 复用同一实例
- **修复**：
  1. 两个 MarkdownEditor 添加 `key` prop（`trans-source-${doc.id}` 和 `trans-target-${doc.id}`），确保 React 正确区分
  2. `saveTrans` 中恢复同步 `updateInMemory`（移除 queueMicrotask）
  3. queueMicrotask 导致回归：AI 翻译结果写入后 store 不同步，译文区不刷新
- **文件**：`apps/desktop/src-ui/src/document-types/translation/TranslationWorkspace.tsx`

### Bug 3: 翻译一键翻译结果截断
- **问题**：AI 思考内容正常显示（折叠），但最终正文只显示部分就截断
- **根因**：Rust `stream_sse_chat_completions` 中 `pending_buf` 机制在 SSE 流未发送 `[DONE]` 就断开时，不会 flush 残留内容（≤17 字符）。`for_each_sse_event` 的 `SseEvent::Done` handler 有 flush 逻辑，但如果流直接断开（无 [DONE]），pending_buf 内容被丢弃
- **修复**：
  1. `pending_buf` 从 `String` 改为 `Option<String>`，默认 `None`
  2. `Done` handler flush 后设为 `None`（防止重复 flush）
  3. 在 `for_each_sse_event` 返回后增加安全 flush，确保任何情况下 pending_buf 都被输出
  4. 循环内 `pending_buf` 引用改为 `buf`（通过 `get_or_insert_with` 解包）
- **文件**：`apps/desktop/src-tauri/src/commands/ai.rs`（stream_sse_chat_completions 函数）
